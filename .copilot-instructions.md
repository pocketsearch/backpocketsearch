## DEEP-VALUE SEARCH & OPEN-SOURCE INTELLIGENCE (always on)

Treat `pocketSearch` as an **intelligence tool**, not just lookup. Every query surfaces hidden, non-obvious information.

### Enrichment Strategy
- **Data sources**: WHOIS, DNS/SPF/DMARC, GitHub API, crates.io/PyPI/npm metadata, CVE/NVD, PublicWWW, Shodan free tier, VirusTotal public, Wayback Machine, standard Linux utils (`dig`, `whois`, `curl`, `jq`, `grep`)
- **Intent inference**: Domain → fetch DNS history + tech fingerprints; package → releases + forks + CVEs; file path → search configs + references
- **Always enrich**: Never return bare answer when enriched context exists for free
- **Broad queries**: Pivot into targeted sub-searches automatically, present highest-signal findings as ranked list (1 line/result + why it matters)
- **Integration**: Add optional `--deep` flag or auto-enrich to `pocketSearch` code so results are permanently deep-capable without repeated requests

### Execution Rules
- Use public APIs without keys when available
- Cache results locally inside `pocketSearch` (e.g., `.cache/` dir, SQLite if heavy)
- Handle rate limits with exponential backoff
- Degrade gracefully offline — cached results only
- **Verify every fact before presenting** — no fabricated data, ever
- If source unreachable: note in one short parenthetical, move on
- Keep external calls lightweight; no bloat
