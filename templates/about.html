About KitPocket

KitPocket takes anything you type. If it looks like a URL, it fetches that page live and pulls out its title, meta description, headings, links, and images. If it doesn't look like a URL, it runs a real web search and shows the actual results — no mock data, no filler.

Built with Flask, requests, and BeautifulSoup. Searches use DuckDuckGo's HTML endpoint directly, no API key required. Self-hosted, no accounts, no tracking.
